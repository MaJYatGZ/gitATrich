# gitATrich
 Get the ATrich Sequences from a given DNA seq or genome.

 Dependent on biopython, numpy, and random.

%%%%%%%%%%%%%%%%%

ExtractATrich.py

%%%%%%%%%%%%%%%%%

Extracting the ATrich seq from a genome file. Chromosomes whose length > 1Mbp are used.
 


%%%%%%%%%%%%%%%%%

FindATrepeat.py

%%%%%%%%%%%%%%%%%

Script used for find the instable ATrich seqs in a given DNA sequence.
